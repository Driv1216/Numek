# Overall evaluation

Open a workflow folder and choose a dataset by its difficulty and name. Each evaluated dataset opens directly to its analyzed input, the **Recommended** report in PDF and native HTML where available, and **Dataset and Findings.md**. Open **Additional Analyses** for a different input, declaration, or view of the same dataset. Original attempts, including the failures, are under **Technical Evidence**.

The qualification established useful evidence for the analyzed populations. Small examples make the checks easy to inspect. Large and unusual cases show how DataTrust reports coverage, bounded work and blocked checks. Practitioner acceptance remains unassessed.

## Where to start

- **Simple** · Start with balanced Iris classification or the 414-row real estate analysis.
- **Medium** · Compare the Bank Marketing prediction-time declarations or check the fuel economy measurements.
- **Complex** · Review Superconductivity’s bounded search, Oxford pet annotations, or linked GDP documents.
- **Ultra Complex** · Open the one-million-row New York taxi analysis, the full-width Gisette report, or the Electricity panel.

Difficulty reflects what DataTrust actually analyzed, including width, grouping, media, timing declarations, and execution scope. The same source can have different difficulty in different workflows.

**Input** files are the actual retained analysis inputs. Where multiple workflows use the same file, their Finder entries open the shared bytes inside this library. Save a separate copy before editing an input. For images and documents, keep the companion assets with the manifest or use the saved configuration.

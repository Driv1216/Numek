# Problems and limitations

## What changes how you should read reports

- **Electricity.** The full panel's nominal clocks left elapsed-time continuity blocked. The separate 64-row report shows the corrected disclosure. The large panel remains useful for coverage and measurements within its declared clock scope.
- **Gisette.** Inspection profiled 500 columns, listed 2,000 and omitted 3,001 from the listing. This is a different scope from the recommended analysis of all 5,000 predictors.
- **Oxford cats and dogs.** Historical mask reports use the old frame-mismatch wording for four photos with invalid EXIF orientation. The corrected six-image report identifies the reason. The recommended full breed annotation report answers the separate classification question.
- **Classification rounding.** The legacy Iris missing-label result rounds to 81.83. The original oracle expected 81.82. The calculation order is documented and the original discrepancy is retained.
- **Availability and interpretation.** An association can be real and still be unavailable at prediction time. The bank, fuel economy, appliance, and taxi declarations demonstrate the distinction. Read the declaration before using a finding.
- **Generalization.** Broader recovery combinations, forced spill under default scratch, natural-text semantics, comprehensive image-mask correctness, and universal workload limits remain unestablished. Both optional cross-representation model profiles remain inactive. The COCO caption benchmark has a retained outcome and ledger, with no pair of native reports from that benchmark.
- **Human review.** External practitioner acceptance remains unassessed. The retained evaluation is analytical, automated, and agent-assisted.

## Replay and source exceptions

- Use the configuration under a dataset's **Technical Evidence** for a fresh execution. It uses the relocated input and asset paths. Earlier paths inside the technical archive remain historical. A resulting native report can bind fresh private evidence to the relocated input.
- Sealed historical private locators depend on exact path and file identity. Their old absolute bindings and selected disclosure exports are preserved. Reopening an old private locator may require a fresh replay, even when the report itself opens.
- The benchmark under **Complex - COCO Image and Caption Association** is an evaluated frozen case with source inputs and results, rather than an ordinary product report. Open its dataset findings for the scope and outcomes. The current shipping product keeps the profile inactive.
- Open Images, Household Power Consumption, and Mulan Scene have provenance or reserve material in the technical archive. This library contains no evaluated run with a recommended report for those entries.

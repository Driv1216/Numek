**Remaining defects and reproductions**

**D1 — Invalid regression selective-risk confidence bounds. Acceptance blocker; newly identified statistical defect.**

At [policy_assessment.py:279](/Users/drivyaanshyadav/Desktop/Numek/src/confidenceguard/policy_assessment.py:279), `_interval` selects binomial inference whenever the metric belongs to `RATES` and the *observed sample* happens to contain only zeros and ones. `RATES` includes `selective_risk`, but [policy_metrics.py:165](/Users/drivyaanshyadav/Desktop/Numek/src/confidenceguard/policy_metrics.py:165) computes regression selective risk using the declared numeric loss. An observed 0/1 sample does not make that loss a Bernoulli random variable.

Public-path reproduction: constant numeric policy 0; 40 independent E rows with outcome 0; regression `selective_risk`, absolute loss, true declared bounds `[0,10]`; one required claim `le 0.1`, alpha 0.05. `optimize_policies → freeze_policy_family → assess_policies` returns **supported**, interval **[0, 0.08809730287880237]**, and `finite_sample_under_declared_assumptions`.

A valid IID loss population assigning probability 0.95 to loss 0 and 0.05 to loss 10 has mean **0.5**, so this claim is false. The all-zero E sample occurs with probability **0.95^40 = 0.12851215656510312**, already exceeding the total 0.05 error budget. All observations respect the declared bounds; all policies issue. This is an actual finite-sample validity failure, not a missing-label, dependence or false-bound limitation.

Reproduction: [cg5_statistical_probe.py](/private/tmp/cg5_statistical_probe.py). Evidence: [statistical results](/private/tmp/cg5_statistical_probe_results.json).

**D2 — Family-local tolerance nomination loses the correct global nominee. Acceptance blocker; residual R05.**

[milp_family:515](/Users/drivyaanshyadav/Desktop/Numek/src/confidenceguard/policy_optimization.py:515) returns only its local tolerance nominee plus an objective reference. [search:779](/Users/drivyaanshyadav/Desktop/Numek/src/confidenceguard/policy_optimization.py:779) submits only that returned policy to global nomination. [hybrid_family:635](/Users/drivyaanshyadav/Desktop/Numek/src/confidenceguard/policy_optimization.py:635) likewise keeps only one nominee per routing branch. A policy tied around a local optimum need not be tied around the global optimum; another locally evaluated policy can be the correct global tie winner.

Reproduction maximizes `correct_issue_rate`, absolute tolerance **0.65**, relative tolerance 0. A two-choice admitted MILP family has policies scoring **0.6** with complexity **[4,1]**, and **0** with complexity **[3,1]**. Its local nominee is the simpler zero-score policy. An explicit candidate scores **1.0** with complexity **[5,0]**. Relative to global optimum 1.0, score 0 is ineligible but score 0.6 is eligible and simpler than the explicit candidate.

Full enumeration correctly nominates **0.6**. `search` and supervised `optimize_policies` nominate **1.0**, while the MILP family reports complete coverage and `solver_optimal_encoded_model`. The large declared tolerance is legal; it makes the loss of the globally eligible policy easy to inspect. Display retention is not responsible: all details fit.

# Packaging scope and limitations

## Included, with original bytes

- Complete current `src/confidenceguard` and `src/datatrust` runtime/static files;
  all tests and repository test fixtures; permanent docs; package/build metadata
  and platform/build/schema dependency locks.
- All CG5 contracts, interpreter, metric/store adapters, backends, assessment,
  history, persistence, CLI/API/browser/report integration and generated schemas.
- Original CG5 baseline, final source map, preservation audit, executed test logs,
  strict schema results, finite diagnostics, governing measured inputs/results,
  synthetic retained workspaces/packets, protected family, final report samples
  and browser/PDF visual evidence.
- CG1–CG4 authored validation tools/docs and retained result evidence, including
  negative/unfinished experiments. Immutable CG4 source-only capsules are an
  explicit exception to the normal `.nosync` environment exclusion. Two prior
  synthetic protected fixtures are retained because existing receipts name them.
- Authored legacy validation helpers needed to trace retained tests, plus their
  specifically required accepted small fixture. Unrelated modality datasets are
  not redistributed as a new CG5 requirement.
- A new clean-source wheel with exact parity for 212 runtime/static files; build
  log and parity receipt. The metadata retains package version 0.1.0, not an
  invented distribution version for this review.

The complete per-file hashes and sizes are in [MANIFEST.json](../MANIFEST.json).
The capture/exclusion inventory is [PACKAGING_INVENTORY.json](PACKAGING_INVENTORY.json).
The existing verified source digest binds 190 extension-selected files; the archive
manifest additionally covers all remaining source/assets, tests, docs and evidence.

## Explicit exclusions

No Git internals, real credentials/private keys, `.env` files, local Python
installations/virtual environments, package/model caches, bytecode, OS metadata,
unrelated frontend laboratories, portfolios or external datasets/model weights
are included. Transient browser-host state is excluded. Superseded CG5 partial
and duplicate scratch runs are excluded because they are not governing evidence;
the verification record preserves their failure/survival explanation.

Earlier complete CG3/CG4 review ZIP deliveries are excluded as nested superseded
handoffs. Their relevant current source, evidence, metadata and snapshots are
provided directly. This is an explicit scope choice, not an omitted authority or
substitution of old scientific claims. Historical source-capture ZIPs and synthetic
backup archives that are evidence are retained.

A [text privacy scan](PRIVACY_SCAN.json) found no high-confidence private-key,
provider-token, access-key or credential-URL matches in selected text inputs.
The fixture/record data selected for CG5 is synthetic engineering evidence.
This scan is not a proof that every imaginable secret pattern has been recognized.
Protected synthetic packets contain synthetic IDs/costs and original machine paths;
those paths are retained for provenance and may require rebinding for new runs.
No customer/person-level production dataset or host/session credential store is
included. Test tokens and synthetic launch strings in source are deliberate fixtures.

## References and portability

Every local path link in the five current review instruction documents must resolve
inside the ZIP. [REFERENCES.json](REFERENCES.json) also checks preserved historical
Markdown documents and records exceptions rather than rewriting their original
bytes. Such exceptions concern old review deliveries, excluded local dependencies,
external datasets/models, archive-relative historical examples or files already
absent from the starting repository. They are not silently represented as included.
Historical absolute code paths and relocated old context links are mapped to
included members in the reference index; their old line annotations are not
revalidated. Old CG4 reviewer probe attachments are included with original hashes.
The completed reference preflight resolved all 718 local Markdown path references,
including 30 historical mappings, with zero unresolved references.
Use the current entry point for this CG5 review, not older review quickstarts.

The archive contains dependency locks and a source wheel, not every dependency
wheel, model weight or native library. Review installation may need network access
and native dependencies. No new installation, workload run, result regeneration,
full test rerun, independent review or acceptance occurred during packaging.
The existing comprehensive gate and final affected checks are reused through
[the evidence guide](EVIDENCE_GUIDE.md).

## Packaging verification and authority

The adjacent external integrity receipt records duplicate/unsafe entry checks,
CRC, full manifest coverage, each payload hash/size, parity with the verified
source map and safe extraction with a second complete hash comparison. The ZIP's
exact checksum and size are reported alongside it. The manifest cannot contain
its own final hash; the external ZIP checksum covers it.

These checks establish the delivered bytes and packaging completeness within
this disclosed scope. They do not self-approve CG5, resolve independent-review
findings, declare deployment readiness or authorize CG6.
